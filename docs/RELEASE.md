## DockX — док і Dynamic Island для Windows

**Як встановити:** завантаж **DockX-Setup.exe** нижче й запусти. Права адміністратора не потрібні.

- **DockX-Setup.exe** — інсталятор (ярлик на столі, автозапуск, видалення через «Програми»)
- **DockX-portable.zip** — без встановлення: розпакуй і запусти `DockX.exe`
- **DockX-demo.mp4** — відео з усіма функціями

### Що всередині
- Док як у macOS: збільшення іконок, перетягування, запущені програми, кошик
- Dynamic Island як у Nusa: музика з будь-якого плеєра (Spotify, YouTube у браузері…) і караоке-тексти в одному острові
- Батарея й зарядка, полиця файлів, буфер обміну, фокус-таймер, вода, справи, віджети, нагадування про молитви
- Вікно налаштувань, усе зберігається автоматично
- Написано на Rust, один файл ~1,5 МБ

Windows 10 / 11, x64.
